## 1. 퀴즈 보상 유물 시각 각성 (R24 즉시 도입분)

정답 순간 5가지가 동시에 일어납니다.

1. **발밑 빛기둥 폭발** — 유물색 세로 광주(HD 가산 합성) + 바닥 확장 고리 + 회전 룬 고리 + 상승 불티, 화면 섬광 · 짧은 슬로모션 · 70틱 무적
2. **상단 유물 각성 배너** — 유물 아이콘(메달) · 이름 · TI.2/TI.3 · "참격 진화 · ○○" · 한 줄 역사 설명 (3.7초, 헤더 아래)
3. **HD 참격 아크 영구 진화** — 유물 3색(코어 · 중간 · 외곽)으로 교체 + 굵기 1.12배 + 끝단 유물 섬광. 적중 시 유물 효과(한 타격 묶음에 1회):
   `shard` 관통 파편 · `quake` 대지 충격파 · `ripple` 공명 고리 · `streak` 질풍/예광 줄기 · `burst` 화약 폭발
4. **무기 · 전신 오라** — 원화 백색 실루엣을 유물색으로 물들여 번진 후광(무기가 있는 앞쪽이 더 밝음), 평소 맥동 + 무기 쪽 불티
5. **HUD 유물 칩** — 주인공 이름 앞 16px 아이콘

## 2. 레벨 기술 해금 · 진화

| 레벨 | 내용 | 연출 |
|---|---|---|
| Lv.1 | 3단 콤보 · 점프 · 막기/저스트 패링 · 돌진(기본) · 크래시 · 아이템 — 즉시 개방 | 어퍼 버튼 자물쇠 + `LV.2` 배지, HUD `▸LV.2 어퍼` |
| Lv.2 | 어퍼컷/띄우기(L · X) 해금 | 자물쇠 파괴 섬광 + SKILL UNLOCK 배너 + 동료 대사 |
| Lv.3 | 4타 피니시 개방 + 돌진 진화 | SKILL EVOLVE 배너 · 공격/돌진 버튼 섬광 · 첫 2회 `4-HIT FINISH!` |
| Lv.5 | 각성기 → 진(眞) 각성 오의 | TRUE AWAKENING 배너 · 각성 버튼 이름 `진(眞) 각성` |

- 잠긴 기술 입력: 둔탁한 소리 + 머리 위 `🔒 LV.2` 팝업 + 버튼 흔들림(0.5초에 1번)
- 콤보: Lv.1~2는 1→2→3 순환(4~6시대 3타 = 사격 그대로), Lv.3부터 1→4 순환
- 돌진: 기본 = R23 값(사거리 245 · 피해 1.65 · 4타, 잔상 7 → 4) / 진화 = 사거리 290 · 깊이 76 · 피해 2.15 · 5타 · 밀어내기 15 · 속도 33 · 무적 36 · 유물/시대색 잔상 10 + 2연 참격 + 충격파
- 각성기: 기본(Lv.1~4) = 참격 3연 · 일반 2.6×6 · 보스 2.3×8 / 진(Lv.5+) = R23 값 그대로(참격 5연 · 3.5×8 · 보스 3×10) + 황금 빛기둥. 시대 마무리 퀴즈로 터지는 각성은 레벨과 관계없이 항상 진.
- 레벨 곡선은 그대로(처치당 55exp, 100 + 90/레벨): 1시대 기준 Lv.2 ≈ 2처치 · Lv.3 ≈ 6처치 · Lv.5 ≈ 18처치(1시대 목표 24처치).
- 데이터: `SKILL_LV` · `SKILL_UNLOCKS` · `nextSkillOf`.

## 3. 4시대 척준경 리디자인 (첨부 이미지 기반)

- 참고 이미지에서 가져온 것: **의상 · 분위기** — 투구 대신 상투관 + 동곳, 바람에 날리는 장발, 흑철 어린갑(물고기 비늘 갑옷), 육각 호심경, 흑색 전포 · 붉은 안깃, 피 묻은 결사대 무신의 표정.
- 가져오지 않은 것: **배우의 얼굴**. 상업 게임에 실존 배우 얼굴을 옮기면 퍼블리시티권 문제가 생길 수 있어 얼굴은 독자 디자인으로 그렸습니다. 호심경 문양도 쌍룡 원형으로 바꿨습니다.
- 무기는 R19 투자자 확정안(창 + 화통도감 화포) 유지.
- 원화 14장: `idle · run ~ run8 · atk_prep · atk1 · atk1_2 · atk2(화통 사격) · hit` → R23 로더가 자동으로 **8프레임 질주 · 3프레임 찌르기**(선딜 → 찌르기 → 잔심)로 재생.
- 찌르기 2장(atk1 · atk1_2)은 512 캔버스 안에 창끝이 들어오도록 몸을 왼쪽으로 옮겨 그렸고, `ACTOR_SPEC.era4_hero.poseDX = { atk1: 44, atk1_2: 46 }`로 제자리에 되돌립니다(참격 궤적도 같은 보정). 찌르기 궤적 `thrust: [258, 228, 501, 130]`.
- **제작 방식(중요)**: 이미지 생성 모델이 아니라 코드로 그렸습니다(SVG 관절 리그 → Chromium 2배 렌더 → 512 축소). 그래서 기존 채색 원화보다 선명한 벡터 톤입니다. 생성기는 `tools/r24-art/`에 있습니다.
  - Gemini 사용량 한도가 풀리면(11/25 00:31) 이 14장을 포즈 · 의상 가이드로 다시 칠해 **같은 파일 이름으로 덮어쓰면 코드 수정 없이 반영**됩니다(512×512 · 접지선 y=470 · 오른쪽 보기). 몸을 표준 위치에 그린 찌르기 원화라면 `poseDX`를 지우고 `thrust` 좌표만 새 창끝에 맞추세요.
  - R23 원화로 되돌리기: `shinsi-R23/assets/hero/era4_hero_*.png` 6장을 복사하고 새 8장(run3~run8 · atk_prep · atk1_2)을 지운 뒤 MANIFEST에서도 빼면 됩니다.
- 유물 아이콘 17종도 같은 방식(SVG)으로 그렸습니다.

- **정직한 판정: "매 초 55fps 이상" 기준은 이 환경에서 통과하지 못했습니다.** 매번 6초 중 1초가 51~54로 떨어집니다.
- 다만 평균 fps · 렌더 시간은 R23과 같거나 낫고(평균 57~58 vs 57.0, 렌더 4.7ms vs 5.0ms), 전 구간 HD를 유지했습니다(화질 단계 하강 0회).
- ⑥ 진단에서 놓친 프레임 19개는 렌더가 4~9ms뿐이었습니다(16.7ms 예산 이내). 즉 R24 그리기 비용이 아니라 이 헤드리스 소프트웨어 GPU 환경의 프레임 합성 · 스케줄링 지연입니다. R23도 같은 환경에서 p95 33ms입니다.
- 규칙상 부하 측정은 1회여야 하지만, 실패를 고치느라 R24 6회 + R23 기준선 1회를 돌렸습니다. 마지막 변경(HUD 유물 칩의 CSS drop-shadow 제거, 작업만 줄어드는 변경) 뒤에는 부하 측정을 다시 돌리지 않았습니다.
- 권장: 실제 GPU가 있는 기기(투자자 시연 노트북 · 휴대폰)에서 1회 확인.
